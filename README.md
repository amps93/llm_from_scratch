# LLM From Scratch

RTX 4060 Ti 16GB 한 장에서 **PyTorch로 decoder-only 언어모델을 직접 구현하고, 가중치를 무작위 초기화해 학습**하는 교육용 프로젝트입니다. 토크나이저, 데이터 처리, 모델 구조, 사전학습, 대화 학습, 평가 과정을 순서대로 구현합니다.

기존 LLM의 가중치나 완성된 모델 구현은 사용하지 않습니다. K2 Horizon의 공개 데이터·아키텍처·학습 방법은 참고 자료로 활용하고, AI Hub 데이터는 한국어 학습에 사용합니다. 데이터 이용 조건은 각 출처에서 확인합니다.

## 현재 단계

설계를 마쳤고, 모델 구현은 시작 전입니다. 첫 작업은 작은 PyTorch 모델에서 causal attention과 loss를 검증하고 작은 배치를 과적합시키는 것입니다. 약 1억 파라미터 모델은 그다음 단계에서 GPU 메모리와 처리량을 측정한 후 학습합니다.

- [HANDOVER.md](HANDOVER.md): 다른 장소에서 작업을 이어가기 위한 현재 상태와 다음 작업

## 새 PC 또는 새 Codex 세션에서 시작하기

1. 저장소를 클론하거나 기존 저장소에서 최신 `main`을 받습니다. 로컬 변경이 있으면 먼저 확인합니다.
2. `HANDOVER.md`의 현재 상태와 다음 작업을 읽습니다.
3. 현재 PC의 Python·PyTorch·CUDA·GPU 환경을 확인하고, 결과를 `HANDOVER.md`에 기록합니다.
4. Codex에는 “`AGENTS.md`, `HANDOVER.md`, `PLAN.md`를 확인하고 다음 작업부터 이어서 진행해줘”라고 요청할 수 있습니다.

학습 데이터와 체크포인트는 PC마다 별도로 관리하며 GitHub에 올리지 않습니다. 환경 설치 명령과 학습 실행 명령은 실제 구현이 추가되면 이 README에 기록합니다.
